# Architecture decisions

Public ADRs in this directory are written from first principles for v2.

Rules:

- each ADR is self-contained;
- normative decisions, invariants, failure behavior, rejected alternatives, and
  acceptance criteria are explicit;
- discussion history and private-document locators are excluded;
- fixtures are derived from the ADR, never the reverse;
- executable mirrors cannot amend an ADR by becoming green.
