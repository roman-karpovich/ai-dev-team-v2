# Technical spikes

Spikes reduce implementation uncertainty and produce decisions, fixtures, and
measured evidence. They are not production engine code.

Current spikes:

- [schema](schema/README.md)
- [snapshot](snapshot/README.md)
- [sandbox](sandbox/README.md)

Each spike must state its question, candidates, fixtures, measurements, exit
criteria, and decision. Throwaway implementations stay inside their spike
directory.
